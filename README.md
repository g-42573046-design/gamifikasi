The game should be an original endless runner game inspired by the fast-paced feel of Subway Surfers, but do not copy copyrighted characters or official game assets. Make it look fresh, original, and suitable for primary school students.
Main concept
The player is a schoolboy who runs forward automatically on a track.
The objective is to collect only verbs and avoid non-verbs and barriers.
The player must get as many points as possible.
Gameplay
- The game title is: VERB RUNNER
- Subtitle: Collect the Verbs! Avoid the Non-Verbs!
- The player controls a boy character.
- The boy runs continuously forward automatically.
- The game uses a 3-lane runner system.
- The player must move left, move right, and jump to collect correct words and avoid danger.
Keyboard controls
Use keyboard controls:
- Left Arrow = move to the left lane
- Right Arrow = move to the right lane
- Up Arrow = jump
Make the controls smooth and responsive.
Player mission
The student joins as the player and must:
- run forward
- collect all correct verbs
- avoid all non-verbs
- avoid all barriers / obstacles
Lives
- The player has 3 lives only
- Show 3 heart icons at the top of the screen
- If the player hits a non-verb or barrier, lose 1 life
- When all 3 lives are gone, the game ends
Scoring system
The player earns points only by collecting verbs.

Each verb has a score value:
- easy verbs = 10 points
- medium verbs = 20 points
- better verbs = 30 points
- difficult / special verbs = 50 points
Show a floating score animation like:
- +10
- +20
- +30
- +50
Display:
- Score
- Best Score
- Lives
- Verbs Collected
Examples of verbs to collect
Use clear action words such as:
- run
- jump
- read
- write
- eat
- drink
- sing
- dance
- play
- sleep
- swim
- climb
- laugh
- draw
- cook
- listen
- speak
- throw
- catch
- build
Examples of non-verbs to avoid
Use words that are clearly not verbs, such as:
- cat
- table
- chair
- pencil
- school
- flower
- bag
- apple
- car
- house
- teacher
- doctor
- book
- red
- blue
- happy
- tall
- beautiful
- window
- ball
Make sure the incorrect words are clearly non-verbs and do not confuse students.
Barriers / obstacles
Add barriers such as:
- wooden boxes
- rocks
- traffic cones
- broken fences
- road blocks
- logs
The player must jump over or avoid these obstacles.
Difficulty
- Start easy and slow
- Gradually increase speed as score gets higher
- Spawn more verbs, non-verbs, and obstacles over time
- Keep it fun and suitable for young learners
Visual style
Use attractive comic-style graphics.

Important visual requirements:
- colourful and appealing
- comic-like illustration style
- original art, not copied
- bright and energetic environment
- boy character should look cheerful and active
- smooth animation
- fun school-friendly atmosphere
- interesting background with road, trees, buildings, and playful elements
- use strong outlines, bold shapes, and lively colours like a modern children’s comic
The game should feel like a comic adventure endless runner.
User interface
Create:
1. Start Screen
   - title: VERB RUNNER
   - subtitle: Collect the Verbs! Avoid the Non-Verbs!
   - button: Start Game
   - button: How to Play
   - simple instructions for controls
2. Game Screen
   - score at top
   - lives at top
   - best score
   - verbs collected
   - pause / sound button if possible
3. Game Over Screen
   - text: Game Over!
   - show final score
   - show best score
   - show total verbs collected
   - button: Play Again
   - button: Main Menu
Feedback and effects
When the player collects a correct verb:
- show sparkle effect
- show score popup
- play positive sound
- show encouraging words like:
  - Great!
  - Excellent!
  - Good job!
  - Awesome!
When the player hits a non-verb:
- lose 1 life
- show message: Oops! That is not a verb!
When the player hits a barrier:
- lose 1 life
- show message: Watch out!
Technical requirements
Build this as a fully playable interactive game, not just a mockup.

Requirements:
- Use HTML, CSS, and JavaScript (or Gemini Canvas supported framework)
- Arrow keys must work properly
- Prevent arrow keys from scrolling the page
- Character movement must be smooth
- Collision detection must work correctly
- Jumping must work correctly
- Random spawning of verbs, non-verbs, and obstacles
- Game must restart without refreshing the page
- Save best score if possible
- Responsive and suitable for desktop browser
Most important requirement
This must be a real playable learning game where:
- a student enters as the player
- the boy runs automatically
- the player collects only verbs
- the player avoids all non-verbs and barriers
- the player has only 3 lives
- the player tries to get the highest score possible
